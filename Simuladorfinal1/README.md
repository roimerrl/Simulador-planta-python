\## Descripción General

Este proyecto es una aplicación de línea de comandos (CLI) escrita en Python que simula el funcionamiento de una planta industrial durante \*\*5 jornadas de producción\*\*. El usuario asume el rol de supervisor y toma decisiones operativas frente a incidencias para equilibrar calidad, cumplimiento y costos.
